## 每份簡報的內容

1. **封面**：被罰件數、罰款合計、最高罰款
2. **被罰原因**：醫療效能／誇大不實／健康食品超出核准範圍
3. **被罰說法**：這一年實際被罰的說法與件數
4. **真實案例**：產品、罰款、被罰原句
5. **改寫對照**：被罰說法 → 建議改法 → 法規依據
6. **合法來源**：附件一、附件二、健康食品可用的說法，以及「允許詞句也會被罰」的實例

## 使用前請注意

- 本資料僅供刊登前自我檢查參考，不構成法律意見；實際是否違規，以主管機關認定為準。
- 衛生局依「整體表現」判斷，改寫後仍需連同圖片、影片、品名一起檢查。
- PowerPoint 檔的每張投影片是圖片，文字無法直接修改；「備忘稿」附有講者說明。

## 修改與重新輸出（給維護者）

簡報原始檔在 `src/`，每類一個資料夾：`deck.json` 是頁面順序，`slides/*.html` 是各頁內容。修改後在專案根目錄執行：

```bash
.venv/bin/pip install -r scripts/requirements-slides.txt
.venv/bin/python scripts/export_slides.py check   # 檢查有沒有內容超出版面
.venv/bin/python scripts/export_slides.py build   # 重新產生 PDF 與 PPTX
```

需要本機安裝 Google Chrome。
